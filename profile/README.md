# Agent Authority Conformance

An LF Decentralized Trust lab hosting conformance vectors, verifier adapters and reproducible run reports for agent identity, delegated authority, signed decision receipts, attribution and provenance.

## Bring your work

Anyone can bring a test case, a run report, a failing result, an alternate implementation or a proposal for a new agent-authority corpus. You do not need an invitation, an APS implementation or a passing result.

Start with an issue that says what you want to test and links any code, vectors or results you have. Incomplete work is welcome. Early discussion helps most when the scope is new, so nobody duplicates work.

A submission can be published as a candidate before anyone has independently reproduced it, with its evidence and review status stated next to it. Admission to a reviewed corpus is a separate decision under that corpus's published criteria. Participation in the lab is not certification or endorsement.

- Report a run or a failure: https://github.com/Agent-Authority-Conformance/aps-conformance-suite/issues/new?template=run-report.yml
- Propose a candidate: https://github.com/Agent-Authority-Conformance/aps-conformance-suite/issues/new?template=candidate.yml
- Propose a new corpus: https://github.com/Agent-Authority-Conformance/aps-conformance-suite/issues/new?template=new-corpus.yml

## Corpora

- [aps-conformance-suite](https://github.com/Agent-Authority-Conformance/aps-conformance-suite): the initial corpus, targeting the Agent Passport System (IETF draft-pidlisnyi-aps).

Other agent-authority specifications can bring their own corpus, with a defined normative target and an identified maintainer. Those two requirements apply when the lab agrees to host a corpus, not to opening the conversation. Results from each corpus stay distinguishable.

## How runs work

Every published run names who ran it, which implementation and revision were tested, and whether the run was author-produced or independent. The lab certifies nothing and issues no conformance verdicts. A maintainer decision is not consensus.

Run a corpus and report: https://github.com/Agent-Authority-Conformance/aps-conformance-suite/blob/main/docs/RUN-REPORT.md
